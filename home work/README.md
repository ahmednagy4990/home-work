# منصة المتميز في الفلسفة وعلم النفس

## تشغيل الموقع محليًا

لا تفتح `index.html` بالنقر المزدوج؛ خدمة FormSubmit لا تعمل من عنوان `file://`.

من داخل مجلد المشروع شغّل:

```powershell
python -m http.server 5500
```

ثم افتح:

`http://localhost:5500`

## النشر على GitHub Pages

ارفع `index.html` و`teacher.png` إلى المستودع، ثم فعّل GitHub Pages من:

`Settings > Pages > Deploy from a branch`

بعد نشر الموقع، استخدم رابط GitHub Pages وليس ملف HTML المحلي. أول إرسال سيحتاج إلى تأكيد البريد من رسالة FormSubmit تصل إلى `ahmednagy4990@gmail.com`.
